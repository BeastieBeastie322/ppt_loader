# Оборудование для трансляций
**Конспект для слушателей · ТЕХ ГУАП · направление ПТС**

Подробный конспект по презентации `PTS-oborudovanie.html` и тексту лектора.

## Тезисы на занятие

— Какая задача → какое соединение → какое оборудование.
— Карта эфира: источник → путь → обработка → вывод.
— Источники: камера, ПК/ноутбук, внешний сигнал.
— Тракт, кабели и интерфейсы: HDMI, SDI, XLR, Ethernet.
— Преобразователи: конвертер, адаптер, сплиттер, соединитель.
— Обработка: микшер, скейлер, матрица.
— Станция: захват, вывод, GPU, стрим/запись, звук.
— Практика: четыре типовые задачи и диагностика тракта.

## 1. Логика занятия

Цель — не каталог моделей, а цепочка: **какая задача → какое соединение → какое оборудование**. Спецификации подтягиваются на практике; здесь важны роли узлов в тракте.

## 2. Карта мира эфира

**Трансляция** — путь аудиовидеосигнала от места события к зрителю (эфир, запись, удалённый зал, платформа).

Четыре блока:

1. **Источник** — камеры, ПК/ноутбуки, внешний сигнал
2. **Путь** — кабели, сеть, преобразователи
3. **Обработка** — микшер, скейлер, матрица, станция
4. **Вывод** — стрим, запись, экраны зала

**Диагностика:** если эфир «упал», идите слева направо и ищите, где сигнал умер.

## 3. Источники сигнала

### 3.1. Камеры

**Источник сигнала** — устройство, которое впервые формирует видео и отдаёт его наружу вместе с параметрами формата.

Выходы: **SDI (BNC)**, **HDMI**, иногда **NDI**. Параметры: разрешение, частота кадров, progressive/interlace.

**В первую очередь проверяем здесь:** формат, выход и другие параметры источника. Без стабильного сигнала с камеры дальше чинить бессмысленно.

### 3.2. ПК и ноутбуки

Источник **компьютерной графики**: презентации, браузер, окна, титры.

- **Выход:** HDMI / DisplayPort / USB-C → при необходимости адаптер
- **Сетевые протоколы:** NDI, SRT, RTMP и др.
- **EDID** — данные о дисплее; без них ПК может отдать неверный режим

**Важно:** HDMI на ноутбуке/ПК — **всегда** только выход, не вход. Для входа нужна карта захвата.

### 3.3. Внешний сигнал

Уже готовая программа: PGM с другого микшера, плеер/медиасервер, ВКС/телемост. У внешнего сигнала тоже есть интерфейс и формат — согласуйте их как у камеры.

## 4. Базовые термины

- **Интерфейс** — способ взаимодействия и обмена данными между устройствами (разъём + правила обмена): HDMI, SDI, USB, Ethernet.
- **Протокол** — набор правил, по которым устройства «понимают» друг друга: RTMP, SRT, NDI, TCP/IP.
- **Формат** — полный набор параметров сигнала: разрешение, частота кадров, развёртка, кодирование, иногда цвет и звук.
- **Тракт сигнала** — упорядоченная последовательность звеньев от источника к конечному приёмнику.

## 5. Кабели и интерфейсы

Кабель = **разъём + протокол + ограничения по длине**.

| Интерфейс | Суть |
|-----------|------|
| **HDMI** | Видео+звук, короткие линии, чувствителен к кабелю и EDID |
| **SDI (BNC)** | Проф. видео; Level A/B — упаковки 3G; длиннее и стабильнее HDMI |
| **XLR** | Балансный звук |
| **Ethernet (RJ45)** | Сеть, управление, стрим и передача по IP |

## 6. Преобразователи сигнала

Общее обозначение устройств на пути: смена стандарта, разветвление, согласование разъёмов, соединение линий.

### 6.1. Конверторы

**Конвертер** меняет **стандарт** сигнала (типично HDMI ↔ SDI), часто с питанием и чипом. Может делать up/down/cross и embed/de-embed звука.

**Правило:** разные разъёмы **и** разные протоколы → конвертер, не переходник.

### 6.2. Адаптеры

**Адаптер** меняет только форм-фактор разъёма (HDMI ↔ DVI). Не превращает HDMI в SDI и не чинит формат кадра.

**Ошибка новичка:** ждать от адаптера работу конвертера.

### 6.3. Сплиттеры

**Сплиттер (DA)** — один вход, несколько одинаковых копий на выходы (микшер + рекордер + превью). Активный сплиттер предпочтительнее пассивного разветвителя.

### 6.4. Соединители (бочонки)

**Бочонок** — механическое стыкование двух однотипных кабелей (BNC–BNC и т.п.). Каждое лишнее соединение — точка отказа.

### Типовая связка

**Камера HDMI → конвертер HDMI→SDI → SDI-сплиттер → микшер / запись / превью.**

Где ошибаются: адаптер вместо конвертера; нет питания; путают параметры сигнала.

## 7. Обработка

### 7.1. Видеомикшер

Выбирает PGM/PVW, делает переходы, PinP, ключи.

- **PGM** — программа (эфир)
- **PVW** — превью (следующий кадр)
- **AUX** — дополнительный выход

Пример: **Roland V-60HD** (4× SDI + 2× HDMI; PGM / AUX / Multi-View; звук).

### 7.2. Скейлер

**Скейлер** приводит кадр к нужному формату отображения (разрешение, стороны, ориентация) без искажения пропорций.

**Кейс:** 1920×1080 → экран 768×1280. Решение — fit/crop. Ошибка — stretch. Пример: Roland VC-100UHD.

### 7.3. Матрица / Videohub

**Матрица** — M×N с независимыми маршрутами. Сплиттер раздаёт копии; матрица переключает назначения.

- Спереди — управление; сзади — разъёмы SDI
- Пример: Blackmagic Smart Videohub 20×20

## 8. Станция: захват, вывод, GPU

### 8.1. Карты захвата

- **USB** — внешний бокс к порту; удобно для ноутбука
- **PCIe** — плата в слот (x4/x8/x16); выше запас по полосе

**Как отличить:** корпус на кабеле vs «гребёнка» в слот.

### 8.2. Вывод программы

Возврат программы в тракт — **не** мониторный выход игровой видеокарты.

- Внешний бокс (пример: UltraStudio Monitor 3G)
- PCIe SDI + HDMI playback

HDMI ПК — всегда только выход и не заменяет вход захвата.

### 8.3. Видеокарты (GPU)

На станции GPU нужен для:

- **композиции** — слои, переходы, ключи, NDI
- **кодирования** — NVENC и аналоги
- **мониторинга** — несколько экранов оператора

Мониторный HDMI с GPU **не заменяет** профессиональный вывод в тракт.

## 9. Стрим, запись и звук

### 9.1. Стриммеры и рекордеры

Железный рекордер/стриммер пишет и/или отдаёт эфир отдельно от ОС станции — страховка архива. RTMP/SRT на платформу; Program/ISO на SSD.

### 9.2. Звук и синхрон

Аудиоинтерфейс — когда звук идёт отдельным трактом. «Звук отстаёт» → разные пути → **delay / lip-sync**. Семплрейт обычно **48 kHz**.

## 10. Практика: четыре задачи

### Задача 1

**Условие:** камера только HDMI; нужен микшер SDI и рекордер HDMI.

**Решение:** HDMI-сплиттер + конвертер HDMI→SDI. Копия HDMI → рекордер; вторая копия → конвертер → микшер SDI.

### Задача 2

**Условие:** ноутбук со слайдами → микшер только с SDI-входами.

**Решение:** HDMI с ноутбука → конвертер HDMI→SDI → микшер.

### Задача 3

**Условие:** камера SDI → vMix на станции для стрима.

**Решение:** карта захвата SDI (USB или PCIe) → станция → стрим.

### Задача 4

**Условие:** один SDI на микшер и рекордер одновременно (оба SDI).

**Решение:** активный SDI-сплиттер (или матрица при сложных маршрутах).

## 11. Итоги и диагностика

Сначала задача, потом тип соединения, потом железо — а не наоборот.

Источник → путь → обработка → вывод.

**Алгоритм диагностики:**

1. От источника к конечному приёмнику.
2. На каждом звене: есть ли сигнал (lock), верный ли формат, есть ли питание.
3. Устранение — сразу после последнего звена, где сигнал ещё был штатным.
4. Не путать адаптер и конвертер; не путать мониторный HDMI GPU с выводом в тракт.
