# Презентация ПТС · вводное

## Как открыть
Скачай **`PTS-vvodnoe.html`** и открой двойным кликом в Chrome / Edge / Firefox.

Фото уже вшиты в файл — отдельная папка `assets` не нужна.

**Управление:** ← → / пробел · **F** — полный экран

## Файлы
- `PTS-vvodnoe.html` — презентация
- `PTS-vvodnoe-tekst.md` — текст к слайдам (для лектора)
- `assets/` — исходники фото (на показ не обязательны)
