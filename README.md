# Презентации ПТС · ТЕХ ГУАП

## Как открыть
Скачай HTML и открой двойным кликом в Chrome / Edge / Firefox.

**Управление:** ← → / пробел · **F** — полный экран

## Файлы

### Вводное
- `PTS-vvodnoe.html` — презентация (фото вшиты)
- `PTS-vvodnoe-tekst.md` — текст к слайдам

### Оборудование для трансляций
- `PTS-oborudovanie.html` — презентация (фото вшиты; ~по плану занятия)
- `PTS-oborudovanie-tekst.md` — подробный текст лектора с терминами
- `assets/equipment/` — исходники фото + ATTRIBUTION.md
- `scripts/build_pts_equipment_deck.py` — пересборка HTML
