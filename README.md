## Как открыть презентацию

- **HTML** — открой двойным кликом в Chrome / Edge / Firefox. Управление: ← → / пробел · **F** — полный экран.
- **PPTX** — копия для PowerPoint / Google Slides / Keynote.

## Шаблон новой темы

Когда готовим занятие — создаём **отдельную папку** и кладём туда весь комплект:

```
<тема>/
  PTS-<slug>.html          # презентация (основная, с фото)
  PTS-<slug>.pptx          # копия для PowerPoint
  PTS-<slug>-tekst.md      # текст спикера
  PTS_<Тема>_konspekt.pdf  # конспект для слушателей
  PTS_<Тема>_konspekt.md   # тот же конспект в Markdown (по желанию)
  README.md                # что внутри папки
  assets/                  # исходники фото (если нужны)
  scripts/                 # скрипты сборки темы
```

Общий конвертер HTML → PPTX:

```bash
python3 scripts/html_deck_to_pptx.py путь/к/презе.html -o путь/к/презе.pptx
```
